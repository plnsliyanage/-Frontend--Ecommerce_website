# Loop & Lace Frontend (React + Vite)

Frontend for the crochet clothing ecommerce project.

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in the project root:

```env
VITE_API_URL=http://localhost:5000
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```

`VITE_API_URL` must point to the existing backend API used by this project.

## Verification

```bash
npm run lint
npm run build
```
